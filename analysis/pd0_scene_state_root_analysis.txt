1. State gate in g.m()
- Reads field v (byte).
- If v == 1: performs n(), w(), u(), then c(y*22, A*16), resets T=false, and iterates i=0..19 over boolean array a[20].
- For each enabled a[i], reads entity/slot id k = a[g + i] (g is a short offset into byte array a).
- Calls a(B, i, 0, c[k] - 0) via private a(BII), then sets N=1.
- For i==7 or i==8, calculates a secondary Y-like parameter from b[k], d[k] and calls a(558, a[k]-68, computedY).
- Reads mode byte a[g+20+i]. If mode==1 calls a(525,0,aw). If mode==2 calls a(530,0,300-ba-aZ+aw).
- Thus 525, 530, and 558 are literal command/tree indices passed from this state-1 branch; they are not proven to be top-level screen roots.

2. State gate when v != 1
- If v == 0, calls F().
- If v is any other value, m() returns without this branch's work.
- Therefore scene traversal depends on game state v, but the branch for v==1 also loops over enabled slots and invokes multiple trees/commands, not one single root.

3. Recursive tree renderer g.a(int index, int x, int y)
- Reads packed b[9][index]. Low 13 bits are the start index; bits 14–15 are a 2-bit pre-command selector.
- If pre-command selector != 0 and E is false, calls leaf renderer b((selector-1)*3+1, x, y).
- Child count is j[16][index] & 63.
- Each child is read from b[10][childIndex]. Low 13 bits are target index; bits 14–15 yield y-offset (top-two-bit value * 128); bit 13 chooses recursion.
- Child x offset is j[18][childIndex], y offset is j[19][childIndex] plus packed y-offset.
- If bit 13 is clear, calls leaf renderer b(target, x+xoff, y+yoff). If set, sets E=true around recursive a(target,x+xoff,y+yoff), then resets E=false.
- E prevents the special pre-command from firing recursively.
