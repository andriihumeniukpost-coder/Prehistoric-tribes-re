/pd0 recursive scene/command graph — bytecode-grounded analysis
Target: Prehistoric Tribes v0.1.38, decompiled g.class
Scope: final void a(int,int,int), private void b(int,int,int), and referenced tables.

1. Root record (b[9])
At g.a(int,int,int), the method reads b[9][index] as an unsigned 16-bit word:
  childStart = word & 8191                 (bits 0..12)
  flags      = (word & 65535) >> 14 & 3    (bits 14..15)
If flags != 0 and recursion guard E is false, it first calls b((flags-1)*3+1, x, y).
Then it traverses child records from childStart through childStart + (j[16][index] & 63) - 1.
Thus b[9] is a node/record descriptor, not a direct pixel offset. j[16] provides a low-six-bit child count.

2. Child record (b[10])
For each child word:
  childId     = word & 8191                 (bits 0..12)
  yLayerDelta = ((word & 49152) >> 14) << 7 (bits 14..15 scaled by 128)
  recurse     = (word & 8192) >> 13         (bit 13)
If bit 13 is zero, the method calls b(childId, x + j[18][childIndex] + yLayerDelta, y + j[19][childIndex]).
If bit 13 is one, it sets E=true, calls a(childId, adjustedX, adjustedY), then resets E=false.
The guard prevents the optional root preamble from being applied recursively in the same way.

3. Direct drawing leaf
private b(int,int,int) reads j[20][childId] & 31. For mode < 27, it selects image a[0][mode], uses j[21] & 127 and j[22..24] for source rectangle geometry, and calls the drawRegion wrapper. Modes >=27 use the separate special drawing branch. This connects the recursive graph to the actual renderer.

4. Validation note
The table index/count relationship above is directly derived from bytecode. The report CSV decodes every b[9] word and checks whether childStart + count stays within the decoded b[10] table; the check is a sanity check only and does not assert all table entries are roots or all values are semantically valid scene roots. For any index whose j[16] entry is absent, the count is blank.
