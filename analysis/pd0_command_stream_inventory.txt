PREHISTORIC TRIBES v0.1.38 — /pd0 COMMAND STREAM INVENTORY
========================================================================

Evidence sources: f.class private void b() bytecode; tools/dump_pd0.py; parsed original JAR resource /pd0.

RESOURCE LAYOUT
- /pd0 size: 97,417 bytes; parser consumes all 97417 bytes.
- First byte is skipped by loader.
- Next 11 tables are big-endian signed-short arrays; their lengths are the first 11 entries of the loader's size table.
- Next 25 tables are signed-byte arrays; their lengths are the remaining 25 entries.
- j[17] has 42 bytes, i.e. 14 RGB triplets by size. The render code indexes this array as RGB triples; semantic names for colors are not present in this resource.
- j[20]–j[24] are five parallel arrays, each 1,832 entries, and form the geometry/command parameter stream used by g.b(int,int,int).

BOUNDARIES / LIMITATIONS
- This report inventories the resource and dispatcher, not a semantic mapping from command index to named game object.
- b[9] contains 1,731 entries, but its low-13-bit values are not all direct offsets into the 1,832-entry j[20] stream; many exceed its bounds. Do not treat every b[9] record as a draw-command span without tracing the other dispatch tables and flags.
- No original game code or JAR resource was modified.
